What is Ferz?

The built-in Ferz engine is designed to play in an aggressive, human-like style at approximately 2250 ELO. It doesn't just find the strongest move — it fights for the initiative, launches kingside attacks, sacrifices material for activity, and creates the kind of tactical complications that make chess exciting.

Supports classical chess, computer tournaments, game analysis, opening books, and more — all in one self-contained program with a clean dark-themed interface.

Features

♟

Built-in Ferz Engine

Aggressive human-style engine (~2250 ELO) that plays for initiative and attacks. Handcrafted Evaluation, UCI protocol, adjustable time controls, parallel games.

🎮

2D & 3D Board Views

Switch between classic 2D and immersive 3D perspective view. Smooth animated transitions and full dark theme in both modes.

🌙

Dark Mode

Clean dark theme throughout the entire application — board, panels, menus, and dialogs.

📋

PGN Database & Explorer

Built-in PGN database with game explorer, move-by-move statistics, and database management. Import and export PGN files.

🏆

Computer Tournaments

Run round-robin or knockout tournaments between engines. Parallel game execution with real-time statistics, win/draw/loss tracking, and detailed summaries.

⚙

Game Analysis

Analyze games with evaluation graphs, per-move eval bars, and detailed move commentary. Step through positions with full navigation controls.

✨

Chess960 (Fischer Random)

Play Chess960/Fischer Random chess for more variety. Randomized starting positions keep your openings fresh.

📖

Opening Books & Tablebases

Support for opening books and Syzygy endgame tablebases (local files + online lookup) for optimal endgame play.

Menus & Controls

Intuitive menu system with access to all features — games, tournaments, settings, and analysis

Console Control

Ferz includes a full built-in console (Ctrl+`) for advanced game control. Type commands directly — TAB autocomplete, command history, and a console log saved to local_games/console.log.

System Requirements

  • OS: Windows 10 / 11 (64-bit)
  • RAM: 2 GB minimum
  • Disk Space: ~150 MB after extraction
  • Processor: x86-64 compatible

How to Install

  1. Download Ferz_SFX.exe using the button above
  2. Run the self-extracting archive
  3. Choose an extraction folder (e.g. C:\Ferz)
  4. After extraction, launch Ferz.exe — no installation required
